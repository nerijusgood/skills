# Third-party assets

- **Icons** (`icons.py`): [Phosphor Icons](https://phosphoricons.com), regular weight, MIT license. Copyright (c) 2023 Phosphor Icons. Full text in `LICENSE-phosphor.txt`.
- **Avatars** (`avatars.json`): [Open Peeps](https://www.openpeeps.com/) by Pablo Stanley, CC0 1.0. Rendered once with the [DiceBear](https://www.dicebear.com) library (`@dicebear/core` and `@dicebear/open-peeps` 9.x, MIT) and stored as data URIs, so the skill works offline.
- **Doodles** (`doodles.py`): original drawings made for this project. No third-party source.
- **Diagrams** (optional): [Archify](https://github.com/tt-a1i/archify) by tt-a1i, Apache-2.0. Not bundled. If the user installs it separately, the `diagram` block embeds the HTML it generates. That generated HTML is Archify output and stays under its license and notices.
